# 2026 年 11 月工作总结

## 摘要

本月围绕中波红外重光照中的**材质建模**展开：把原来"全场景默认非金属"的假设，升级为"物体级金属度 → 物理导出反射率/发射率 → 逐点材质先验约束"的完整链路，并清理了一条物理上错误的旧损失。所有代码在 `add_newidea` 分支（仅本地），CPU 回归测试通过；完整训练实验待服务器执行。

---

## 一、本月主线

中波红外图像 = 自发辐射 + 反射，训练中必须分离发射率 ε 与反射率 ρ。原系统用软约束把 ε 钉在 `[0.6, 0.9]`，等于假设物体为非金属，金属的重光照结果不物理。本月工作：

1. 让"金属/非金属"成为模型可表达的属性；
2. 让 ε 由 BRDF 反射率**物理导出**（Kirchhoff），而不是常数或像素空间约束；
3. 在单温度单光照下用**材质类别先验**打破 ε–ρ–T 简并。

## 二、已完成的工作

### 2.1 反射率 LUT 与 BRDF 分析工具

- 新增 `computebrdf/gen_spec_lut.py`、`spec_lut.npz`：Karis split-sum 的 A/B 查找表（64×64，roughness × N·V）
- 新增 `computebrdf/hemisphere.py`、`slice_reflectance.py`、`_test_lookup.py`、`changeBrdf.py`：半球反射率积分、BRDF 切片导出与自检工具
- 用途：给 ε 提供与渲染口径一致的反射率来源；也用于拟合/对比外部 BRDF 测量

### 2.2 L2 物体级金属度（核心）

| 内容 | 位置 |
|---|---|
| BRDF 金属工作流：`F0 = 0.04(1−m) + bc·m`，`f_d = bc(1−m)/π` | `gaussian_renderer/neilf.py` |
| 四种 ε 模式：`external` / `analytic` / `lut` / `auto` | `gaussian_renderer/neilf.py` |
| CLI：`--metallic`、`--material_prob_path`、`--metallic_from_model` | `arguments/__init__.py`、`train.py` |
| 离线投影投票：逐视角 mask → 遮挡测试 → 逐点 `metal_prob.npy` | `script/prepare_object_metalness.py` |
| VLM 语义查询：可见光照片 → Qwen-VL → `scene_meta.json` | `script/query_vlm_metalness.py` |
| 评测入口同步 | `eval_relighting_syn4.py` |
| CPU 回归测试（BRDF/ε 公式、投影几何） | `computebrdf/_test_l2.py` |

关键设计：`m=0` 时逐位退化为原介电模型；金属度是**固定先验**不参与优化；`metal_prob` 必须是长度 N 的 float32 数组，与阶段一 checkpoint 一一对应（阶段二须 `--densify_until_iter 0`）。

### 2.3 删除了物理错误的发射率约束

旧损失对**渲染后的 sRGB 热辐射图像**做 `clamp(0.6, 0.9)`，而该图像是 `ε·s·T⁴` 经色调映射的结果——量纲不对，约束目标错误（实测在默认 `thermal_scale` 下相当于要求 ε≈3.8~9.3，物理不可达）。

- 已删除该损失块与 `lambda_emission_constraint` 参数（commit `13fe6af`）
- 替换为对逐点 ε 的约束（见 2.4）

### 2.4 逐点材质发射率区间先验

```
ε_i = 1 − ρ_i,  ρ_i = bc_i(1−m_i) + F0_i·A(r_i) + B(r_i)
L_prior = mean[ m_i·h(ε_i; 0.05, 0.65) + (1−m_i)·h(ε_i; 0.65, 0.98) ]
h(e; lo, hi) = ReLU(lo−e)² + ReLU(e−hi)²
```

- 金属点推向低 ε、介电点（含背景，`m_i=0`）推向高 ε → **背景默认非金属**由加权自动实现
- `--lambda_material_prior` 默认 **0.01**（设 0 关闭）；四个区间参数可调
- 只在 `analytic`/`lut`/`auto` 下有效（`external` 的 ε 是常量，无梯度）
- 逐点 ε 依赖 `base_color` 与 `roughness`，先验梯度会同时作用于这两者（已验证方向正确）

### 2.5 base_color 上限：0.80 → 0.95

`scene/gaussian_model.py:51` 由 `sigmoid(x)*0.77+0.03` 改为 `*0.92+0.03`。依据（`spec_lut.npz` 实测，N·V=1）：

| 粗糙度 | 金属 bc=0.80 | 金属 bc=0.95 |
|---|---|---|
| 0.1 | ε=0.20 | ε=0.05 |
| 0.5 | ε=0.31 | ε=0.18 |
| 1.0 | ε=0.75 | ε=0.71 |

旧上限把光滑金属的 ε 钉在 0.2，无法进入真实抛光金属的 0.05 量级。

## 三、关键判断及依据

| 判断 | 依据 | 风险/代价 |
|---|---|---|
| ε 不直接学习，由 ρ 导出 | Kirchhoff 定律；单温度下 ε 与 ρ 简并，独立 ε 会吸收光照误差 | 参数化上限决定 ε 可达区间（已通过提上限缓解） |
| 材质类别用物体级标量，不做逐部件 SAM | 自采数据量小、SAM 在红外域衰减明显；物体级足够区分金属/非金属 | 混合材质场景会误判 |
| VLM 只做语义，不输出物理量 | VLM 对 ε/温度无可靠物理感知 | 需要一个可见光照片目录（可选） |
| 像素空间 clamp 必须删除 | 量纲错误，相当于约束 ε≈3.8~9.3 | 无（默认本来就关闭） |
| 先验作用在逐点 ε 而非渲染图 | 逐点 ε 与参数线性相关，梯度方向可控 | 与光度损失在 bc 上竞争 |
| 先验用 hinge + 软权重，不硬 clamp | 区间内零梯度，不干扰重建；避免 0/1 边界不连续 | 强先验可能压低亮背景的 bc |
| 自采数据两阶段细节正则全 0 | 细节监督（深度/法线/朝向）在自采数据上不可靠，会破坏重建 | 法线无监督、高光方向可能偏 |

- 先验梯度方向实测：金属 ε 过高 → base_color 上升；背景 ε 过低 → base_color 下降、ε 上升
