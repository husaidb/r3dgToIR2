# 逐点材质发射率约束（可写入论文的方法点）

本文说明本次实现的"金属低发射率 / 非金属高发射率"约束的动机、公式、实现位置、消融设计与可辩护的边界，供论文第 X 节改写使用。

---

## 1. 一句话定位

在红外重光照中，把**物体级金属度语义先验**传递到 3D 高斯的每个点上，并据此对**逐点发射率**施加双向区间软约束：金属点被推向低发射率、介电点被推向高发射率，背景默认落在介电一侧。

它不是新的 BRDF，也不是对 Kirchhoff 定律的修正，而是**利用材质类别先验打破单温度单光照下的 ε–ρ–T 简并**。

## 2. 为什么需要这个约束

1. 单波段、单温度、单光照下，观测辐射 `L = ρ·L_env + ε·σT⁴` 中 ε、ρ 与 T 存在尺度简并，仅靠光度损失无法唯一确定材质属性。
2. 基尔霍夫定律 `ε = 1 − ρ` 把 ε 变成反射率的导出量，但反射率由 BRDF 参数化给出，参数化的表达能力决定 ε 的可达区间。
3. 在默认参数化下，金属的高反射率无法被充分表达（`base_color` 上限 0.80，导致光滑金属 ε ≥ 0.2），因此需要（i）放宽参数上限、（ii）对 ε 施加上下界先验，二者配合。

## 3. 方法

### 3.1 反射率与发射率

对第 i 个高斯点，金属度 `m_i ∈ [0,1]` 由离线多视角投影投票得到，固定不优化。BRDF 采用 Disney/glTF 金属工作流：

```
F0_i  = 0.04·(1 − m_i) + bc_i·m_i            # 金属的镜面基色 = base_color
f_d,i = bc_i·(1 − m_i) / π                   # 金属无漫反射
```

半球反射率取 Karis split-sum（N·V = 1，保证每个点只有一个 ε）：

```
ρ_i = bc_i·(1 − m_i) + F0_i·A(r_i) + B(r_i)
ε_i = 1 − ρ_i
```

其中 `A(r), B(r)` 来自预计算的 BRDF LUT（`computebrdf/spec_lut.npz`），`r_i` 为粗糙度。

### 3.2 逐点区间软约束

```
h(e; lo, hi) = ReLU(lo − e)² + ReLU(e − hi)²

L_prior = (1/N) Σ_i [ m_i · h(ε_i; ε_m^lo, ε_m^hi)
                    + (1 − m_i) · h(ε_i; ε_d^lo, ε_d^hi) ]
```

默认区间：金属 `[0.05, 0.65]`，介电 `[0.65, 0.98]`。总损失：

```
L = L_rgb + λ_pbr·L_pbr + λ_prior·L_prior
```

`λ_prior` 默认 0.01（保守值，设 0 即关闭）；若重建质量受损可降到 0，若 ε 分离不够明显可升到 0.03。

### 3.3 三个设计选择及理由

| 选择 | 理由 |
|---|---|
| 作用在逐点 ε，而不是渲染图像 | 渲染值是 `ε·s·T⁴` 经色调映射的结果，与 ε 无线性关系；在像素空间做 clamp 会优化错误目标 |
| 按 m_i 连续加权，而非硬二分 | `m_i` 本身是投票概率，硬阈值会在 0/1 边界产生不连续梯度；连续加权退化为"软过渡" |
| 平方 hinge 只惩罚越界 | 区间内梯度为零，不干扰光度损失；边界梯度平滑 |

### 3.4 "背景默认非金属"如何自然成立

`m_i = object_prob_i × m_obj`，背景与桌面 `object_prob = 0`，因此 `m_i = 0`，其损失项完全落在介电分支：背景被约束为高发射率、低反射率，等价于"默认非金属"。这是逐点版本相对全局标量版本的核心优势——全局 `--metallic` 会把桌面一并当作金属。

## 4. 实现位置

| 文件 | 内容 |
|---|---|
| `gaussian_renderer/neilf.py` | `rendering_equation` 返回逐点 `eps`；`render_view` 计算 `material_prior_loss`；`calculate_loss` 以 `λ_prior` 加权 |
| `arguments/__init__.py` | `lambda_material_prior`、`eps_metal_min/max`、`eps_diel_min/max` |
| `train.py` | 将区间参数注入渲染参数 |
| `scene/gaussian_model.py` | `base_color` 上限由 0.80 提高到 0.95 |
| `script/query_vlm_metalness.py` + `script/prepare_object_metalness.py` | 物体级 metalness 的获取与逐点投射 |

约束仅在 `--emissivity_mode {analytic, lut, auto}` 下生效（此时 ε 是 BRDF 参数的函数，可回传梯度）；`external` 模式下 ε 为常量，先验无梯度。

## 5. 实验设计（消融）

| 编号 | 设置 | 验证什么 |
|---|---|---|
| A | 纯物理，λ_prior=0，上限 0.80 | baseline |
| B | 纯物理，λ_prior=0，上限 0.95 | 参数上限的作用 |
| C | B + λ_prior=0.01/0.03/0.1 | 先验强度敏感性 |
| D | 全局标量 metalness vs 逐点 metalness | 逐点投射的必要性 |
| E | 仅金属区间 / 仅介电区间 | 两个方向各自的贡献 |

监控指标：分区 ε 均值与直方图（金属区、介电区、背景）、`psnr_pbr`、重光照前后对比图、材质参数图。论文中应报告"先验是否改变 ε 分布且未显著损害 PSNR"，而不是只看最终数值。

## 6. 可辩护的边界（审稿人可能追问）

1. **ε 是导出量，不是直接监督目标**：先验通过 base_color/roughness 间接作用，因此写"约束反射率的可达区间，进而约束 ε"，不要写"直接学习发射率"。
2. **Kirchhoff 在此是工程近似**：`ρ` 取 N·V=1 的定向-半球反射率，忽略视角与多次散射；正文需声明该简化。
3. **区间数值是经验先验**：0.05–0.65 / 0.65–0.98 参考抛光金属与常见介电材料的发射率范围，需在实现细节中给出出处或说明为经验设定。
4. **介电下界会压暗高反射背景**：若背景主要靠反射发亮，介电分支会压低其 base_color；实验中应记录背景区域 ε 与重建质量，必要时放宽下界。
5. **类别先验不等于材质真值**：VLM 判定与逐点投票都有误差，`metal_prob` 作为权重天然软化了这一点，但不能宣称标签正确。

## 7. 可直接改写的论文段落（草稿）

> 中波红外成像同时包含自发辐射与反射分量，仅凭单温度观测无法唯一分解二者。本文利用材质类别在宽带反射率上的差异作为额外约束：金属的宽带反射率高、发射率低，常见介电材料的反射率低、发射率高。我们将该差异编码为逐点发射率的区间先验，并以金属度概率作为软权重在金属区间与介电区间之间连续过渡。
>
> 发射率由简化 BRDF 的半球反射率经基尔霍夫定律导出：ε=1−ρ，其中 ρ 采用 Disney 金属工作流的基色参数化并配合 Karis split-sum 的解析积分。发射率因此不是独立优化的参数，而是材质参数的函数，先验通过光度梯度作用在基色与粗糙度上。
>
> 由于金属反射率通常高于参数化上限，我们同时放宽了基色参数的取值上界，使光滑金属的发射率能够进入 0.05 量级；消融实验表明，区间先验在保持重建质量的前提下使金属与介电区域的发射率分布显著分离。
